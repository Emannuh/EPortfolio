Cloud Security Engineering

Defense-in-depth cloud architectures on Azure and AWS — from SIEM and SOAR setup to Zero Trust network design, identity management, and GDPR compliance automation.

What I Deliver

I architect and implement multi-layered cloud security frameworks that proactively detect threats, enforce least-privilege access, and keep your cloud environments compliant. My approach is grounded in real enterprise experience — from securing government-grade ICT infrastructure to deploying SIEM pipelines on Azure.

Every engagement starts with a thorough assessment of your existing posture, followed by a structured implementation roadmap tailored to your risk profile, industry requirements, and cloud platform (Azure, AWS, or GCP).

Threat Detection

Microsoft Sentinel SIEM/SOAR integration with custom alert rules and automated incident response playbooks.

Identity & Access

Azure AD (Entra ID), RBAC, Conditional Access, JIT VM access, MFA, and Privileged Identity Management.

Network Security

VNet segmentation, NSGs, ASGs, Azure Firewall, service endpoints, and private subnet isolation.

Compliance & Governance

GDPR-compliant data classification, ARM/Terraform IaC, database auditing, and vulnerability assessments.
